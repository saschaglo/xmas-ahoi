# Crews

Stand 23.10.2026 · [Übersicht](../README.md)

Eine Crew besteht nur für einen Durchlauf einer Station. Es gibt keine dauerhaften Crews, keine Lobby nach dem Check-in und kein Austreten. Begriffe im [Glossar](../../CONTEXT.md).

- Wer eine Station antippt, wählt „Allein spielen“ oder „Crew bilden“.
- „Crew bilden“ zeigt auf dem Handy einen kurzen Crewcode. Die anderen tippen dieselbe Station an und geben den Code ein. Der Code gilt nur für diese Station.
- Maximal 3 Spieler, alle auf einem Screen sichtbar. Treten zwei Personen gleichzeitig dem letzten freien Platz bei, gewinnt der erste; der zweite sieht „Die Crew ist voll“.
- Wer die Station schon beendet hat, kann nicht beitreten und sieht „Du warst hier schon mal“. Jeder Spieler beendet jede Station genau einmal.
- Wer gerade in einer anderen Station spielt, kann nicht beitreten.
- Jeder drückt „Bereit“. Sind alle bereit, startet die Person, die die Crew gebildet hat, über „Start“. Der Start passiert nicht automatisch, man kann auf eine dritte Person warten.
- Im Spiel löst jede Person auf dem eigenen Handy eine eigene Teilaufgabe ([Crewgröße und Teilaufgaben](../spiele/uebergreifend.md#crewgröße-und-teilaufgaben)).
- Nach dem Ende der Station (beendet, Exit oder [Abbruch](hinweise-abbruch-exit.md)) löst sich die Crew auf. Für die nächste Station bildet sich eine neue, in beliebiger Zusammensetzung.
- Punkte und Schlüssel landen beim einzelnen Spieler; siehe [Karte und Stationen](karte-und-stationen.md).
