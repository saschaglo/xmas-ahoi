# Crews

Quelle: Trilium „Spielkonzept – Ablauf der mobilen Webseite“, Abschnitt „Crews“ · Stand 21.10.2026 · [Übersicht](../README.md)

- Nach dem Check-in wird gefragt, ob man allein oder in einer Crew spielt.
- Gründen erzeugt einen Crewcode. Beitreten verlangt die Eingabe des Codes. Jedes Mitglied kann den Code weitergeben; es gibt keine offene Liste und keine Leitung.
- Maximal 3 Mitglieder, alle auf einem Screen sichtbar. Treten zwei Personen gleichzeitig dem letzten freien Platz bei, gewinnt der erste; der zweite sieht „Die Crew ist voll“.
- Lobby: Jedes Mitglied drückt „Bereit“. Ab 2 Mitgliedern und wenn alle bereit sind, kann die Crew über „Start“ beginnen. Der Start passiert nicht automatisch, man kann auf eine dritte Person warten.
- Bis zum Start der ersten Station kann über das Menü („Weitere Person einladen“) ein drittes Mitglied hinzukommen; die Crew sieht dann den Hinweis „Peter ist noch zur Crew beigetreten“. Haben schon zwei Personen „Bereit“ gedrückt und das Spiel hat begonnen, ist kein Beitritt mehr möglich. Beim Start der ersten Station erscheint der Hinweis: „Ihr startet das 1. Spiel, danach ist es nicht mehr möglich, neue Crew-Mitglieder an Bord zu holen.“
- Austreten ist jederzeit möglich, auch mitten im Spiel. Der Button liegt versteckt (Scrollen oder Untermenü). Der Spielstand bleibt beim Spieler.
- Wer noch nie ein Spiel gespielt hat, kann die Crew frei verlassen und wieder eine andere wählen. Wer nach gespielten Spielen austritt, kann keiner Crew mehr beitreten und keine gründen; er spielt danach allein. Auch der Wiedereintritt in dieselbe Crew ist ausgeschlossen.
- Eine Crew löst sich nicht automatisch auf. Geht in einer Zweiercrew eine Person, muss die verbleibende Person die Crew selbst verlassen. Eine Crew mit nur einem Mitglied kann keine Station spielen.
- Crews auflösen kann zusätzlich das [Admin-Panel](../admin/admin-panel.md); das passiert selten und nur in Abstimmung.
